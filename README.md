This repository contains code related to NJL model and its variants.

## Installation

You can install the package from `GitHub` via `Pkg`.
```
import Pkg;
Pkg.add(url="https://github.com/biplab37/NJLModels.jl")
```
or use the REPL,
```
] add https://github.com/biplab37/NJLModels.jl
```

```
using NJLModels
```
