
# NJLModels {#NJLModels}

This package contains all code related to calculation of the NJL models and bound states masses in it including mesons diquarks and baryons. Also some code related to the calculation of the thermodynamics of the correlations.

## Installation {#Installation}

Using `Pkg.jl` 

```julia
Import Pkg; Pkg.add(url="https://github.com/biplab37/NJLModels.jl.git")
```


or from the `julia REPL`

```julia
] add https://github.com/biplab37/NJLmodels.jl.git
```


Once installed, the package can be used as

```julia
using NJLModels
```
